# v9 发现与阅读交互验证

更新日期：2026-10-10，Asia/Shanghai。当前运行源码位于 `extension/`、`launcher/` 与 `ports/`。
本报告优先于 v8 和更早的历史文档。

## 当前设计

面向 X35S 的 640×480 横屏和纯手柄操作，沿用 v8 的真实窗口匹配、
全屏守卫与四列书架。书架首屏容纳八本书；正文继续使用微信读书原生阅读器。

- 主导航：书架、发现、搜索。
- 发现默认进入“猜你喜欢”，显示四本真实推荐书，包含作者及站方推荐理由。
- 发现第二层：猜你喜欢、榜单、分类。继续阅读不占据发现页面。
- 榜单第三层：飙升榜、新书榜、总榜、神作榜、热搜榜、小说榜、潜力榜。
  每项进入真实的 `/web/category/…` 页面，不用首页榜单摘要代替完整列表。
- 分类提供 21 个真实入口；进入某个分类后，顶部仍能切换其他分类。
- B 从分类书目返回分类入口；从推荐打开书再返回时恢复原书的焦点。

推荐开书前保存当批四本书的链接、封面、标题、作者及推荐理由；
返回时恢复同一批推荐，避免站方重新推荐后原书消失。“换一批”或主动切换栏目
会清除快照。快照挂在外壳区域，避开 Nuxt 初始化时重建的站方内容树。

细榜单和分类筛选独立占第三行。发现第二层的三项各占三分之一宽度，
防止 `flex: 1` 的零基准宽度与全宽筛选条同排，把栏目按钮挤成零宽度。
焦点日志已确认这会触发候选回退到书架；最终源码已移除临时日志。
推荐、榜单和分类返回后都在下一次手柄导航输入时清除返回定位键，
避免后续站方 DOM 刷新把用户移动后的焦点拉回原书。

## 加载与恢复

跨页切换立即显示加载状态。加载状态通过 sessionStorage 跨完整导航保存，
目标内容就绪后解除；最快完成的切换保留约 180 毫秒反馈。
12 秒仍未就绪时显示“重试”和“返回书架”，两项均能用手柄选择并确认。

书架 ready 判断包含书籍、书籍分组和可见的空书架提示，避免空书架持续等待。
验证空书架与长等待时只替换页面 DOM，不删账号藏书或改服务器数据。

原生章节错误使用 `.chapterContentError .retry`。失败时将重试按钮纳入候选，
A 优先触发真实按钮输入；恢复正常阅读后，A 再打开阅读菜单。
这是站方章节错误与外壳导航超时两种不同的恢复入口。

## 沉浸阅读

右侧 `.readerControls` 保留尺寸与 DOM，但设为透明、不可直接命中。
目录 X、A 菜单与阅读设置仍通过本机 `input_bridge.py` 的 CDP 输入操作。
桥接器只在目录或设置输入期间临时允许工具栏命中，结束后立即恢复隐藏状态。

不能用 `display:none`、删除 DOM 或移出屏幕替代这个实现，否则站方要求
`event.isTrusted` 的按钮失去可操作的坐标。

没有修改 `.readerChapterContent` 或 `.preRenderContent` 的布局属性。
正文页、作者照片页和封面页由站方决定；canvas 翻页验证应先选文字页，
因为照片页的图片可以通过独立 DOM 显示，canvas 本身没有文字像素。

## 性能

- 阅读器关闭弹层时只关注章节重试按钮，不遍历整页候选。
- 书架、推荐、榜单、分类和弹层各自限制候选收集范围。
- DOM 变更合并刷新，忽略外壳自身产生的变更。
- 减少重复 DOM 更新与布局读取；只在导航或界面结构改变时更新状态。
- 保留启动器的渲染进程限制、256 MB JS 堆上限和缓存限制。
- 动画仅用于加载指示和短暂入场，支持减少动态效果。

性能采样是当前阅读页面的短时间空闲指标，不代表长时间使用、
下载章节或发现页滚动的总体性能；没有用它推算百分比提速。
最终采样 12 秒：TaskDuration 增量 0.198720 秒，ScriptDuration 增量
0.188996 秒，Layout/RecalcStyle 耗时及次数增量均为 0。
JSHeapUsedSize 为 51,382,944 字节，不是浏览器所有进程的内存占用。

## 复现

从仓库根目录运行；电脑需安装 Python 和 paramiko，并设置 `WEREAD_HOST`、
`WEREAD_PASSWORD` 等连接环境变量。脚本通过 SSH 使用设备本机 CDP 和虚拟手柄。
同一设备上的 UI 测试必须串行运行。

```powershell
python tests/test_discovery.py -v
python tests/discovery_probe.py
python tests/empty_shelf_probe.py
python tests/loading_probe.py
python tests/reader_probe.py
python tests/e2e.py
python tests/settings_probe.py
python -m unittest discover -s tests -p "test_*.py" -v
python tests/final_state.py
```

窗口测试之外，还要检查截图、正文 canvas 实际像素和翻页哈希。
测试先等待新文档及对应外壳就绪，不能把路由刚变化或旧页面仍存在的书卡
当成加载完成；SPA 切换也不能用 `performance.timeOrigin` 是否改变来判定。
