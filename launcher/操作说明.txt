微信读书（掌机版）操作说明
============================

【进入】ES 前端 → ports → Weread

【按键总表】
  十字键      首页/书架 → 移动选中框；阅读器内 → 上一页/下一页
  A           确定（打开书、确认菜单项、输入字母）
              阅读中打开菜单；加载失败时直接重试
  B           返回（退出阅读器 / 关闭弹层 / 上一层）
  X           目录
  Y           翻页
  L1 / R1     上一页 / 下一页
  L2          ★ 掌机菜单（常用）
  R2          跳到页面末尾
  START+SELECT  ★ 退出应用（同时按住约 1 秒）

【掌机菜单】按 L2 唤出：
  书架：搜索 / 书架 / 发现 / 退出
  阅读：目录 / 阅读设置 / 上一页 / 下一页 / 书架 / 退出
  用十字键选择，A 确认，B 取消

【搜索怎么用】（掌机没有实体键盘，用屏幕键盘）
  ① 按 L2 唤出菜单
  ② 十字键选到「搜索」，按 A
  ③ 底部出现屏幕键盘：十字键选字母，A 输入
     · 输入拼音即可（例：huozhe → 搜出《活着》）
     · 「清空」删除全部输入，「删除」退格
  ④ 选到最下方的「搜索」键，按 A 提交
  ⑤ 按 B 可关闭键盘

【退出】START + SELECT 同时按住约 1 秒
  （屏幕上的「退出」菜单项只会给出提示，不会真正退出）

【提示】
  · 登录只需一次（手机扫码），登录态保存在本机，之后免登录
  · 首次打开较慢（约 20-30 秒），属正常
  · 顶部有「书架 / 发现」和搜索按钮，十字键选到后按 A 操作
  · 发现下方是「猜你喜欢 / 榜单 / 分类」，榜单与分类细项也在顶部
  · 切换页面会显示加载状态；等待过久时可选择重试或返回书架
  · 阅读右侧工具栏已隐藏，A 菜单中的目录、设置以及 X 目录仍可使用
  · 从发现打开的书，按 B 会返回原栏目并恢复选中的书
